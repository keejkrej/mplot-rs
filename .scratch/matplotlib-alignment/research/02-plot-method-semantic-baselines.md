# Release-1 plot-method semantic baselines

## Scope and evidence

This note resolves only the eight advertised plotting families against Matplotlib commit `bde111fb4ee0023852b48d48f14436647400663d`. The checkout was verified with `git -C ../matplotlib rev-parse HEAD`. All Matplotlib citations below are commit-relative local paths. Current Rust citations describe the capability being retained or the divergence to remove; they are not evidence that the target behavior is already implemented.

The matrix uses the ticket-01 meanings of `Supported`, `Adapted`, and `Unsupported`. `Supported` means the canonical method/option name and selected behavior match. `Adapted` means the same finite capability is expressed through Rust slices, enums, retained builders, build-time validation, or a discarded Artist return. Anything not positively listed is unsupported.

Common release-1 rules:

- Every method is queued on `AxesBuilder` and returns `&mut AxesBuilder`; `FigureBuilder::build() -> Result<Figure>` is the contextual validation point. This is an `Adapted` replacement for Matplotlib Artist/container returns. Current mplot already queues owned series (`src/panel.rs:249-336`, `src/series.rs:553-673`), while Matplotlib returns the objects cited per method below.
- Numeric vector inputs are one-dimensional, row-major scalar grids are passed as a flat numeric slice plus `nrows` and `ncols`, and option values are typed. Python format strings, `data=`, string enums, arbitrary `**kwargs`, unit conversion, masked-array objects, pandas/PIL inputs, and mutable Artist/container handles are unsupported.
- Length, shape, enum, mutual-exclusion, and finite scalar-option checks are fatal at `build()`. Data `NaN` is not itself a build error where Matplotlib masks or breaks it; infinity is rejected because the finite renderer has no unit/masked-array warning channel. No selected value is clamped, ignored, truncated by `zip`, or silently replaced. This fixes current silent behaviors including line/fill early return (`src/render/primitives.rs:90-102,289-304`), alpha clamping/substitution (`src/series.rs:89-91,344-346`), and histogram `bins.max(1)` (`src/series.rs:288-290`). Matplotlib's corresponding validation sources are cited per family.
- Omitted colors use retained per-Axes cycles, not hard-coded `TABLEAU[0]`: `plot` and `hist` consume the line cycle; `bar` and `fill_between` consume the patch-fill cycle. Explicit color does not consume a needed cycle default. Matplotlib initializes and consumes these cycles in `lib/matplotlib/axes/_base.py:241-260,336-354`; bar/fill choose the patch color in `lib/matplotlib/axes/_axes.py:2256-2304,6160-6164`; hist uses the line cycle at `lib/matplotlib/axes/_axes.py:7529-7538`. Current hard-coded defaults are at `src/series.rs:46-55,212-220,273-280,324-331`.
- All selected plotting methods participate in the existing retained Axes order. Explicit `set_xlim`/`set_ylim` prevents later autoscale from replacing that view, matching Matplotlib's fixed-view rule (`lib/matplotlib/axes/_base.py:3127-3129`).

## Release decision

Release 1 keeps one explicit typed Rust call shape per advertised plotting family and the current option-builder breadth, adding only the semantics necessary to make omitted defaults truthful: retained color-cycle state, horizontal histogram orientation, dynamic imshow/contour extents, imshow's pinned fixed defaults, and locator-derived contour levels. It does not emulate Python overloads or arbitrary kwargs.

The non-negotiable fidelity corrections are: no silent truncation/clamping; `bar` uses `bottom + height`; histogram matches NumPy edge/range behavior; missing line/fill data break paths; box statistics/styles/tick management match the pinned rc defaults; imshow defaults to upper origin/equal aspect/auto interpolation and tightly adopts its reversed default extent; contour defaults to `Auto(7)`/viridis with norm scaled to levels; and text never changes data limits. All eight Artist/container returns are intentionally discarded in favor of `&mut AxesBuilder`.
